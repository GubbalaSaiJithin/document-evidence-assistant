# Git and reproducibility

Use Git commits to record meaningful changes to code and documentation. A useful repository README explains the problem, dataset, setup commands, evaluation, limitations and attribution. Pin direct dependencies and record the Python version to help others reproduce a run.

A random seed controls some sources of variation but does not guarantee identical results across every hardware and library combination. Record the dataset version or checksum, split boundaries, parameters and metrics. Keep API keys, private documents and credentials out of version control. Preserve the upstream license when adapting licensed code.
